# Public Roadmap

## Phase 1: Truthful public foundation

- Canonical positioning and repository map
- Public capability claim ledger
- Architecture, security, contribution, and governance documentation
- Removal or correction of unsupported claims

## Phase 2: Reproducible demonstration

- One-command local demo
- Sample agent registry
- Approval-gated mission lifecycle
- Multi-agent handoff
- Receipt generation and verification
- Emergency-stop demonstration
- Automated smoke tests

## Phase 3: Evidence and reliability

- CI workflows
- Public test matrix
- Versioned release artifacts and checksums
- Threat model
- Failure-injection tests
- Node compatibility matrix
- Sanitized operational evidence

## Phase 4: Extensible platform

- Stable plugin and connector contracts
- Module examples and SDK documentation
- Permissions manifest
- Observability dashboard
- Marketplace design and package signing

## Phase 5: Productization

- Managed deployments
- Enterprise support
- Private AI and edge packages
- Training and certification material
- Domain-specific pilots developed with qualified partners

Roadmap items are plans, not promises of completion or revenue.
