2. **Agents + Control Fabric:** lifecycle, authority, leases, stop/handoff/rollback.
3. **Memory + Continuity:** retrieval, indexing, backup/restore, retention classes.
4. **Comms + Connectors:** Telegram, Discord, email, relay, WebSocket, GitHub, provider, DB, hosted workspaces.
5. **Studio + Media:** text/vision/image/speech/voice/video/publishing.
6. **Trading + Blockchain:** market separation, risk controls, receipts, contract/network ownership evidence.
7. **Public Release Layer:** CI/security checks, demos, release checksums, docs, policy, compatibility matrix.
