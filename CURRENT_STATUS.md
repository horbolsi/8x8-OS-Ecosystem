## Release rule

A capability moves to “implemented and verified” only after the public repository contains reproducible instructions, tests, expected output, limitations, and a versioned receipt or CI result.

## Known gaps

- No single reproducible public end-to-end demo yet
- No consolidated public test and evidence directory yet
- No published threat model or independent security review yet
- No public compatibility matrix for devices and environments yet
- No public stable API contract yet
- No certified medical, industrial, financial, or regulatory deployment
